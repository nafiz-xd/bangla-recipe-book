# Bangla Recipe Book

A collection of classic Bangladeshi recipes with real photos, ingredients and step-by-step cooking instructions.

## Live Demo

https://nafiz-xd.github.io/bangla-recipe-book/

## Features

- 8 beloved Bangladeshi recipes — Ilish Bhaja, Beef Tehari, Chicken Roast, Bhuna Khichuri, Chingri Malaikari, Aloo Bhorta, Masoor Dal and Firni — each with a real food photo, English + Bangla name, time, servings and difficulty
- Search by dish name **or ingredient** (try "egg", "mustard" or "ilish")
- Category filter chips: Main, Curry, Rice, Side and Dessert
- Click any recipe for a full detail view with an ingredients list and numbered cooking steps
- Favorite (heart) any recipe — favorites are saved in your browser with localStorage, plus a "Favorites only" filter
- Clean, modern, fully responsive design — works on phone and desktop

## Tech

- Single self-contained `index.html` with inline CSS and vanilla JavaScript — no build step, no dependencies
- Recipe photos stored locally in `images/` (from Wikimedia Commons)
- Favorites persisted with the Web Storage API (localStorage)
